# Simulador de chapitas · Para Perros

Página única (HTML + fotos + tipografías). No necesita instalar nada.

## Cómo dejar tu sitio de GitHub como simulador

1. Entrá a tu repositorio actual en GitHub.
2. Borrá lo que había del sitio anterior: `index.html`, la carpeta `assets` y el archivo `CNAME` si existe.
3. Tocá **Add file → Upload files** y arrastrá **todo el contenido** de esta carpeta: `index.html`, `.nojekyll`, y las carpetas `img` y `fonts`. Confirmá con **Commit changes**.
4. En **Settings → Pages**, borrá el **Custom domain** (ya no se usa: el dominio ahora es de la tienda). La fuente sigue siendo la rama **main**, carpeta **/ (root)**.
5. En uno o dos minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Editar

- Colores y fotos de chapitas: carpeta `img/`.
- Tipografías: carpeta `fonts/`.
- Teléfono de WhatsApp: línea `const WHATSAPP = '5493465651267';` en `index.html`.
